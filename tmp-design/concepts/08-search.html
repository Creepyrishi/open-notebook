Spec · search & discovery
01 · One anatomy, every nature Type pebble, title, matched passage, provenance line — identical bones for source, note, insight, creation and external. Natures never blur: honey card = yours, dashed = not in the library, derived carries its trail.
02 · Hybrid by default Text + semantic, fused. Without an embedding model the mode chip quietly reads “text only” — a label, never an error. The video result shows why semantic earns its keep: it matches the idea, not the words.
03 · Same components as conversation These result cards, the evidence dress and the adopt flow are the very components the chat agent uses when it cites (see 06 — Citations). Manual search and the agent differ only in who is driving.
04 · Discover → reference → adopt The external card carries its receipt (URL + retrieved date). “Use once” cites without filing; “Add as source” adopts into a notebook you pick. Adoption is always an explicit user decision.
05 · Adoption states The external pebble hardens as it crosses the boundary: candidate ↓ opened citable ↓ add as source adopting… ↓ processed adopted ✓ source
06 · Result → evidence continuity Clicking a result opens the same reader anatomy a citation click opens — the first result lands in 02 — Source scrolled to the matched chunk. One preview surface to learn, everywhere evidence appears.
07 · Bigger than Sources The searchable universe includes notes, insights, creation transcripts and the open web — the library is the center of gravity, not the boundary.
